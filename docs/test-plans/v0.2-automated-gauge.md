# Test plan: rain from an automated government gauge (candidate version 0.2, second test)

Written 26 November 2026, before any result below was computed. The commit
that adds this file is the record of when it was set. It follows the first
test, `v0.2-rain-source.md`, in which rain from a volunteer gauge in Pacifica
did not improve the forecast.

## Question

Version 0.1 uses a weather model's rain for the two days before the test day
and the forecast for the test day itself. Does rain measured by an automated,
publicly maintained gauge, used for the two days before, forecast the county's
test better?

## The gauge

Pilarcitos Dam (San Francisco Public Utilities Commission; CDEC station PLD),
6 km south of the San Pedro Creek watershed on the coastal side of the ridge.
Daily totals, calendar days, from 9 August 2022, published by the California
Data Exchange Center. Of the automated gauges near Pacifica it is the only one
with a public multi-year record. San Bruno Mountain (county flood district
gauge 41200) is 12 km north and its history is not yet public; it is not part
of this test.

## The silent-zero rule (set now, applied before any scoring)

The Pilarcitos Dam record contains days that read 0.00 while every other
gauge in the area recorded heavy rain (for example 22 to 24 November 2024).
These are outages recorded as dry days. For this test a Pilarcitos Dam daily
value is treated as missing when it is under 0.05 in and, on the same
calendar day, the SFO airport gauge (NWS, ACIS station 23234) recorded 0.25 in
or more. A missing value is replaced by the model's value for that day (the
same value version 0.1 would use), and the number of replacements is reported.
No other adjustment is made to the gauge record.

## Candidates

Same equation as version 0.1, with its own rain input R:
z = b0 + b1 ln(1 + R) + b2 log10(max(G, 1)); P(fail) = 1 / (1 + e^(-z)).

- **A, version 0.1 (baseline).** R = model rain on the test day and the two
  days before (midnight to midnight). Refitted and scored on the same tests
  as D, so that the comparison is like for like.
- **D, automated gauge.** R = model rain for the test day (the forecast part,
  unchanged) plus Pilarcitos Dam rain for the two days before, after the
  silent-zero rule.

## Tests used

County ocean tests at the creek mouth (station LM5) from 11 August 2022 (the
first day with two prior gauge days) to 19 October 2026, drawn from
`open-data/rule_v0_1_worked.csv`. Tests before that date are left out of
both candidates. The ground-wetness index G is unchanged.

## Scoring and the rule for adopting

As in the first test: each year hidden in turn, equation refitted on the
others, hidden-year results pooled; main score the ranking score (area under
the ROC curve) for "fail"; also the ranking score for "far over", the Brier
score and the forward-in-time check (2024, 2025, 2026 from earlier years
only); weights with 90% bootstrap ranges (2,000 re-draws, fixed seed, the
same draws for both).

D qualifies if its pooled hidden-year ranking score for "fail" is at least
0.02 above A's on the same tests. If it qualifies it is logged alongside
version 0.1 from that day, and when it replaces version 0.1 is the author's
decision, recorded here. If not, version 0.1 stays and the result is reported
here all the same.
